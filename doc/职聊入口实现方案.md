# ZenTaoPMS 职聊入口实现方案

## 问题背景

在 ZenTaoPMS 22.1 开源版中，用户需要一个便捷的入口访问"职聊"（Chat）模块。系统原有的 chat 模块需要在左侧菜单手动点击查找，用户希望能够在顶部导航栏与消息铃铛并列显示职聊入口。

## 需求分析

1. **职聊入口位置**：与系统通知铃铛图标并列显示在顶部导航工具栏
2. **技术约束**：
   - ZenTaoPMS 使用 ZIN UI 框架构建现代 SPA 界面
   - 新 UI 使用组件化开发，不使用传统 PHP 模板直接输出 HTML
   - 需要保持与现有 UI 风格一致

## 技术方案

### 1. 界面架构分析

ZenTaoPMS 存在两套 UI 系统：

| UI 系统 | 渲染方式 | 适用场景 |
|---------|----------|----------|
| 传统 UI | PHP 模板 + HTML 直接输出 | 旧版页面 |
| ZIN UI | React 风格组件化渲染 | 新版 SPA 页面 |

首页 `www/index.php` 使用的是 **ZIN UI** 框架，通过 [lib/zin/wg/header/v1.php](file:///Users/whh073/zentaopms/lib/zin/wg/header/v1.php) 组件构建页面结构。

### 2. 铃铛组件分析

通知铃铛通过 `header::messageBar()` 方法渲染，核心代码结构：

```php
public static function messageBar()
{
    // ...
    return dropdown(
        set::arrow(true),
        set::placement('bottom-end'),
        to::trigger(
            btn(
                setID('messageBar'),
                icon('bell', set::size('lg')),
                // 未读消息数量标签
            )
        ),
        to::menu(menu(...))  // 下拉菜单内容
    );
}
```

### 3. 实现方案

参考 `messageBar()` 的实现，新增 `chatBar()` 方法：

**文件**：`/lib/zin/wg/header/v1.php`

**修改内容**：

#### 3.1 在工具栏中添加 chatBar 调用

```php
$toolbar = new toolbar(
    setClass('gap-2'),
    static::quickAddMenu(),
    static::chatBar(),           // <-- 新增
    static::messageBar(),
    static::userBar()
);
```

#### 3.2 新增 chatBar 方法

```php
public static function chatBar()
{
    global $lang;

    return dropdown(
        set::arrow(true),
        set::placement('bottom-end'),
        set::offset(array("alignmentAxis" => -50)),
        to::trigger(
            btn(
                setID('chatBar'),
                setClass('rounded-full bg-gray bg-opacity-10 text-primary-900 text-opacity-70 ring-0 w-9'),
                set::square(true),
                set::caret(false),
                set::size('sm'),
                icon('chat', set::size('lg'))  // 使用 chat 图标
            )
        ),
        to::menu(menu(
            setClass('dropdown-menu'),
            set::style(array('padding' => '0')),
            div(setID('dropdownChatMenu'))
        ))
    );
}
```

## 关键发现

### 1. Docker 容器路径问题

**问题描述**：
- 主机代码挂载到 `/app`
- 容器内 Apache 实际读取 `/apps/zentao`
- 修改 `/app` 下的文件不会生效

**解决方案**：
```bash
# 同步文件到正确路径
docker cp /path/to/file.php zentao-web:/apps/zentao/path/to/file.php
```

### 2. ZIN UI vs 传统 UI

**问题描述**：
ZenTaoPMS 首页使用 ZIN UI (SPA 架构)，不走传统的 `header.html.php` 模板

**解决方案**：
必须在 ZIN 组件中修改，不能修改旧的 `module/common/view/header.html.php`

### 3. 图标渲染优先级

**问题描述**：
ZIN btn 组件在同时设置 `icon` 和 `text` 时，会优先显示图标

**解决方案**：
对于职聊入口，使用纯图标方式（icon='chat'），与 messageBar 风格保持一致

## 部署步骤

1. 修改本地文件 `lib/zin/wg/header/v1.php`
2. 同步到容器正确路径：
   ```bash
   docker cp lib/zin/wg/header/v1.php zentao-web:/apps/zentao/lib/zin/wg/header/v1.php
   ```
3. 重启容器使配置生效：
   ```bash
   docker restart zentao-web
   ```
4. 清除浏览器缓存或强制刷新页面
