# 迭代1功能用户指南

## 1. 聊天功能

### 1.1 概述
聊天功能允许用户创建聊天房间并进行实时交流，支持公共房间、私有房间和与任务、执行、项目相关的房间。

### 1.2 如何使用

#### 1.2.1 进入聊天界面
- 在顶部导航栏点击聊天图标（对话框图标）进入聊天界面。

#### 1.2.2 创建聊天房间
1. 点击"创建房间"按钮。
2. 输入房间名称。
3. 选择房间类型（公共、私有、任务、执行、项目）。
4. 点击"创建"按钮。

#### 1.2.3 发送消息
1. 点击左侧房间列表中的房间进入聊天窗口。
2. 在底部输入框中输入消息内容。
3. 点击"发送消息"按钮或按回车键发送消息。

#### 1.2.4 管理房间成员
1. 进入聊天房间后，点击右上角的"成员"按钮。
2. 在弹出的模态框中，输入用户账号添加成员。
3. 点击"添加"按钮完成添加。

## 2. 通知中心

### 2.1 概述
通知中心显示系统通知，包括任务分配、评论提及、代码提交和Jenkins构建状态等。

### 2.2 如何使用

#### 2.2.1 查看通知
- 在顶部导航栏点击通知图标（铃铛图标）查看通知列表。
- 未读通知会显示红色圆点标记。
- 点击通知项查看详细信息。

#### 2.2.2 标记通知为已读
- 点击通知项自动标记为已读。
- 或在通知中心中批量标记已读。

## 3. 代码仓库集成

### 3.1 概述
代码仓库集成支持GitLab和GitHub的Webhook，当代码提交时，系统会自动关联提交与任务。

### 3.2 如何配置

#### 3.2.1 配置GitLab Webhook
1. 进入代码仓库页面（顶部导航栏）。
2. 复制GitLab Webhook URL。
3. 登录GitLab，进入仓库设置。
4. 找到Webhook设置，粘贴复制的URL。
5. 选择触发事件为"Push"。
6. 保存设置。

#### 3.2.2 配置GitHub Webhook
1. 进入代码仓库页面（顶部导航栏）。
2. 复制GitHub Webhook URL。
3. 登录GitHub，进入仓库设置。
4. 找到Webhook设置，粘贴复制的URL。
5. 选择触发事件为"Push"。
6. 保存设置。

### 3.3 提交消息格式
为了使代码提交与任务自动关联，请按照以下格式编写提交信息：

```
任务 #123: 完成登录功能

详细描述...
```

其中`123`是任务ID，系统会自动将此提交与任务关联。

## 4. Jenkins CI/CD集成

### 4.1 概述
Jenkins CI/CD集成允许用户配置Jenkins服务器，接收构建状态通知，并将构建结果与任务关联。

### 4.2 如何配置

#### 4.2.1 添加Jenkins服务器
1. 进入Jenkins页面（顶部导航栏）。
2. 点击"创建"按钮。
3. 输入服务器名称、URL、用户名和API token。
4. 点击"测试连接"按钮验证连接是否成功。
5. 点击"保存"按钮完成添加。

#### 4.2.2 配置Jenkins Webhook
1. 登录Jenkins，进入系统设置。
2. 找到Webhook设置，添加新的Webhook。
3. URL格式：`http://your-zentao-url/zentao/jenkins-webhook.html`
4. 选择触发事件为"构建完成"。
5. 保存设置。

### 4.3 查看构建状态
- 当Jenkins构建完成时，系统会自动接收构建状态并生成通知。
- 构建状态会显示在相关任务的详情页面。
